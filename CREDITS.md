# Asset Credits

## Procedural geometry

The apartment shell and all furniture are generated at runtime with three.js.
No external 3D model files (glTF/GLB) are bundled.

## CC0 textures and HDRI

- `public/textures/oak-*`, `walnut-*`, `linen-*`, `marble-*`, `plaster-*` —
  1K PBR textures from [ambientCG](https://ambientcg.com/) (CC0).
- `public/hdri/kloofendal_48d_partly_cloudy_puresky_1k.hdr` —
  Pure Sky HDRI from [Poly Haven](https://polyhaven.com/) (CC0).
